# Model Pricing & Value

A dependency-free static page showing [OpenCode Go](https://opencode.ai/docs/go)
model pricing with a "Value" column: **monthly credit ÷ output price** (million
output tokens your credit covers per month). Higher is better — the best-value
model is starred and highlighted.

## Features

- Sortable table (click any column header; arrows show the active sort)
- Effective-cost columns for Input / Output / Cache Read / Cache Write:
  `price ÷ (10 × monthly credit)` — the price normalized per ten months of
  credit (lower is better)
- Filter by included-usage tier ($15 / $30 / $60 / free)
- Value column + best-value banner
- Dark / light theme toggle (persisted)
- Status pill: shows whether data is live or an embedded snapshot, and why

## How the data stays fresh

Browsers cannot fetch opencode.ai directly (no CORS headers), so the page
loads data from three same-origin sources, in order:

1. `/api/mdlc-pricing` — the local proxy (`serve.py`)
2. `./data/models.json` — committed refresh (the static-host path)
3. direct upstream — only if CORS is ever granted

`data/models.json` is regenerated by `.github/workflows/refresh-pricing.yml`
**every 30 minutes** (also triggerable manually in the Actions tab), or by
hand:

```bash
node tools/update-snapshot.mjs
```

The upstream parser lives in exactly one place, `pricing-core.js`, shared by
the browser and the refresh script.

## Serve it

Locally (with live data):

```bash
python3 serve.py 8097
# → http://127.0.0.1:8097/
```

Locally (static, snapshot data only):

```bash
python3 -m http.server 8097
```

Or just open `index.html` in a browser — everything works offline from the
embedded snapshot.

## Files

| File | Purpose |
|---|---|
| `index.html` / `styles.css` / `app.js` | The page |
| `pricing-core.js` | Shared pure helpers (parser + formatters), browser + Node |
| `data/models.json` | Committed live-data refresh consumed by the page |
| `tools/update-snapshot.mjs` | Regenerates `data/models.json` from the upstream page |
| `.github/workflows/refresh-pricing.yml` | 30-minute automated refresh |
| `serve.py` | Local static server + same-origin live-data proxy |

Data source: [opencode.ai/docs/go](https://opencode.ai/docs/go) — prices per 1M
tokens, subject to change.
